# Designer Quality Gates

Use this scorecard before finalizing any UI. If the interface scores below 8/10, revise it.

## 10-point scorecard

Score each category from 0-1:

1. **Product clarity:** The screen immediately communicates what it is for and what the user can do.
2. **Hierarchy:** The most important content and action visually dominate without confusion.
3. **Layout:** Alignment, grouping, grids, and responsive behavior are intentional.
4. **Spacing rhythm:** Spacing follows a consistent 4px/8px system and relationships are clear.
5. **Typography:** Text scale, line-height, weight, and measure are readable and expressive.
6. **Visual style:** Color, radius, shadows, surfaces, and imagery create a coherent product mood.
7. **Interaction states:** Hover, pressed, focus, selected, disabled, loading, empty, error, and success states are represented where relevant.
8. **Iconography:** Real icons are consistent, correctly sized, and accessible; emojis are not used as production icons.
9. **Accessibility:** Contrast, labels, keyboard support, touch targets, and reduced-motion concerns are handled.
10. **Platform fit:** The interface follows the conventions of web, desktop, mobile, iOS, Android, or cross-platform context.

## Revision protocol

If any score is weak:

- Rework hierarchy before changing colors.
- Fix spacing and alignment before adding effects.
- Replace generic cards with product-specific content structures.
- Replace emojis with an icon system.
- Add missing states and accessibility affordances.
- Re-check on narrow, medium, and wide viewports.

## Visual critique prompts

Ask these questions internally:

- Would a user know what to tap/click first within 3 seconds?
- Does this screen look like the specific product category or a generic dashboard template?
- Is there enough whitespace for the interface to breathe?
- Are important elements aligned on shared axes?
- Are colors meaningful, accessible, and restrained?
- Are icons from one family and matched to the copy?
- Does the mobile layout feel native rather than squeezed desktop UI?
- Would this look acceptable in a portfolio case study screenshot?
