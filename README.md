# AI Creator Autopilot

AI Creator Autopilot is an all-in-one AI platform for creators (especially faceless creators) that can learn a creator's style, generate optimized content, and auto-publish with minimal human input.

## Product vision

Set your content style once, then let AI create, optimize, schedule, and publish content daily.

## Primary users

- Faceless content creators (YouTube automation, TikTok/Shorts niche pages)
- Secondary: on-camera creators who want AI editing and posting assistance

## MVP focus

The MVP is intentionally scoped to faceless creators and 1–2 platforms (TikTok + YouTube Shorts):

1. Style learning from existing creator content
2. Faceless content creation pipeline
3. Trend-based sound integration
4. Scheduling and auto-posting

See `docs/product-requirements.md` for the detailed PRD and `docs/mvp-architecture.md` for a proposed system design.
